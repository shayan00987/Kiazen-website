# Kaizen Health & Wellness — Website Redesign

A responsive green-and-white wellness website using **Kaizen Health & Wellness** content and brand details from https://shayan00987.github.io/kaizen-health-wellness/, with a modern section layout inspired by https://haroondentalclinic.com/. This is not a dental clinic website.

## Files
- `index.html` — website structure/content
- `styles.css` — responsive styling
- `script.js` — mobile navigation, client-story carousel, consultation request
- `assets/` — supplied profile portrait and Pexels-hosted wellness imagery when downloads were available

## Preview and publish
Open `index.html` in a browser, or upload the contents of this folder to a static host such as GitHub Pages.

## Before publishing
- The consultation form opens WhatsApp to **0326 8666 884**; it does not store requests on a server.
- Confirm the current contact details, locations, clinician credentials, and service offerings before publishing.
- Client quotes are carried over from the existing Kaizen website; ensure you have permission to publish them.
- Health-related content is general information and should not be presented as individual medical advice.
- Pexels images are used for illustrative wellness photography. If local image downloads were unavailable, the site falls back to the corresponding Pexels image URL and requires an internet connection.


## Local image assets

The hero, consultation, performance/recovery, nutrition, and service-card photos are custom AI-generated images included in `assets/`. The site references these local files, so those photos do not depend on Pexels or another external image host. The original founder/profile photo is retained separately as `assets/founder-profile.jpg`. A Kaizen-style logo PNG is included at `assets/kaizen-logo.png`. Google Fonts may still load from Google when an internet connection is available; the website and images remain usable without them.
