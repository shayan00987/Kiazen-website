# Kaizen Health & Wellness — Responsive Website

A standalone, responsive front-end website based on the Kaizen Health and Wellness brand direction with an integrated, natural AI-style Concierge Chatbot.

## Included Files
- `index.html` — Complete page markup with integrated concierge chatbot
- `styles.css` — Responsive styling, visual system, organic ambient glow and scroll-reveal transitions
- `script.js` — Mobile navigation, modal consultation form, service selection, smooth scrolling, and scroll observation
- `chatbot.js` — Natural AI-style Concierge chatbot engine (realistic typing delays, smart fuzzy intent matching, dynamic chips, Web Audio sound synthesis, direct booking modal integration, WhatsApp/Call actions)
- `chatbot.css` — Isolated concierge chat interface styles with modern glassmorphism and spring curves
- `assets/` — Original website imagery and the Kaizen logo:
  - `kaizen-logo.png` — Cleaned high-res Kaizen logo
  - `hero-athlete-dna.png` — Hero artwork
  - `science-lab.svg` — Science/laboratory illustration
  - `insight-dna.svg`, `insight-recovery.svg`, `insight-nutrition.svg` — Article illustrations

## Naturality Improvements Added
1. **Empathetic Concierge Voice**: Replaced mechanical, robotic database reads with warm, professional dialogue speaking on behalf of Kaizen's care team ("Better Health Today. Longer Tomorrow.").
2. **Realistic Typing Cadence**: Natural variable typing simulation with bouncing dots (`...`) instead of 0ms instant text dumps.
3. **Interactive Actions in Chat**:
   - `📅 Book Consultation` button directly opens the site's modal and pre-selects the discussed therapy.
   - `💬 WhatsApp Care Team` button directly links to WhatsApp at `0326 8666 884`.
   - `📞 Call Clinic` directly dials `0326 8666 884`.
4. **Dynamic Context-Aware Chips**: Chips dynamically evolve based on user questions.
5. **Web Audio Sound Feedback**: Elegant subtle pop synthesized using the browser's Web Audio API with a one-tap mute button in the header.
6. **Proactive Teaser Badge**: A floating greeting badge welcomes visitors after 3 seconds.
7. **Fluid Organic Site Animations**: Smooth scroll-reveal entrances and breathing ambient hero illumination.

## Run
Open `index.html` directly in any web browser, or serve the directory with any static server.
